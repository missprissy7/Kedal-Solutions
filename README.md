# KEDAL Solutions Website

**kedalsolutions.com** — Intelligent Operations. Amplified Results.

A clean, modern, responsive website for KEDAL Solutions — an AI-powered management consulting firm based in Atlanta, GA.

## Pages

- **Home** (`index.html`) — Hero, services overview, comparison table, industries
- **About Us** (`about.html`) — Story, approach, values
- **Services** (`services.html`) — Four service pillars with details
- **Customers** (`customers.html`) — Case studies and testimonials
- **Contact** (`contact.html`) — Contact form, discovery call CTA, info

## Tech Stack

- Pure HTML, CSS, and JavaScript (no frameworks, no build tools)
- Google Fonts (Inter)
- Responsive design (mobile-friendly)
- Ready for GitHub Pages hosting

## Local Development

Just open `index.html` in a browser. No server needed.

## Deployment

This site is designed to be hosted on GitHub Pages with a custom domain (kedalsolutions.com).
